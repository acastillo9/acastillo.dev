## Architecture

Personal portfolio site for Andrés Castillo built with **Astro 6**, **React 18**, and **Tailwind CSS v4**. Deployed to **Vercel** via `@astrojs/vercel` adapter.

### Rendering model

- Pages are statically generated by default. The contact API endpoint (`src/pages/api/contact.ts`) opts out with `export const prerender = false` and runs as a Vercel serverless function.
- React components (`Navigation.tsx`, `HeroSection.tsx`) use Astro's `client:load` / `client:visible` directives for client-side hydration. All other components are `.astro` (zero JS).

### Content & data

- **Blog posts**: Markdown files in `src/content/blog/`, loaded via Astro Content Layer (`src/content.config.ts`). Schema: title, excerpt, date, readTime, tags, optional image.
- **Site data**: Static data files in `src/data/` — `site.ts` (bio/tagline), `projects.ts`, `skills.ts`, `social.ts`. Edit these to update portfolio content.

### Styling

- Tailwind v4 via PostCSS (`postcss.config.mjs`). No `tailwind.config.mjs` — configuration is CSS-first in `src/styles/global.css`.
- Design tokens (colors, radii) use CSS custom properties with `oklch` color space in `:root`, mapped to Tailwind via `@theme inline`.
- Dark-only theme (no light/dark toggle).
- Fonts: Geist Sans and Geist Mono loaded from CDN.

### Animations

- Scroll-reveal via `data-reveal` attribute + IntersectionObserver in `src/scripts/scroll-reveal.ts`.
- CSS keyframe animations defined in `global.css` (`fade-in-up`, `fade-in`, `glow-pulse`).

### Path aliases

`@/*` maps to `./src/*` (configured in `tsconfig.json`).

### Contact form

Uses Resend API. Requires `RESEND_API_KEY` environment variable.
